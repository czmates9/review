# Instalační balíčky

Tato složka obsahuje instalační balíčky nástrojů potřebných pro vývoj, ladění a údržbu systému FASK.

Velké binární soubory jsou uložené pomocí Git LFS. Po klonování repozitáře proto musí být Git LFS nainstalovaný a aktivní:

```powershell
git lfs install
git lfs pull
```

## Dostupné nástroje

| Nástroj | Účel | Platforma |
| --- | --- | --- |
| [Bruno](Bruno/) | Tvorba a testování požadavků REST API. | Windows x64 |

Každý nástroj má vlastní podsložku s verzí, kontrolním součtem a odkazem na oficiální zdroj.
