# Bruno

Bruno je aplikace pro tvorbu, spouštění a správu testů REST API.

- Verze: `4.1.0`
- Platforma: Windows x64
- Instalační soubor: `bruno_4.1.0_x64_win.exe`
- Oficiální vydání: <https://github.com/usebruno/bruno/releases/tag/v4.1.0>
- SHA-256: `c4fa1fd54be2328570858f13d28804278c9ec9a9f592fb4f71598476cb0e7623`

## Instalace

1. Po klonování repozitáře spusťte `git lfs pull`.
2. Ověřte kontrolní součet instalačního souboru:

   ```powershell
   Get-FileHash .\bruno_4.1.0_x64_win.exe -Algorithm SHA256
   ```

3. Spusťte `bruno_4.1.0_x64_win.exe` a dokončete instalaci.
